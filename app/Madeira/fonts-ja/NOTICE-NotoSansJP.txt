NotoSansJP-Regular.otf: the Japanese font of BCD's Japanese locale

What it is
  Noto Sans JP Regular (version 2.004), the Japanese subset OpenType file of
  Noto Sans CJK. A game with the Japanese locale on (the game page's
  Compatibility > Japanese locale, env.MADEIRA_JAPANESE = 1) gets it linked into
  its prefix's C:\windows\Fonts, and the Windows Japanese font names (MS Gothic,
  MS PGothic, MS UI Gothic, MS Mincho, MS PMincho, Meiryo, Meiryo UI, Yu Gothic,
  Yu Gothic UI, Yu Mincho and their Japanese names) are mapped onto it for that
  game's sessions only (app/Madeira/BCDJapanese.c).

  (LICENSE-NotoSansJP-OFL-1.1.txt, next to this notice; the font carries the
  licence in its own name table too). It is used unmodified and is not sold by
  itself.

How it is carried
  This file is not part of BCD's source repository and is not changed in any way:
  the build downloads it (tools/fetch-japanese-font.sh), checks its SHA-256 and
  puts it next to this notice. It is a data file read by Wine's font code, not a
  program linked with BCD, so it stays under its own licence beside BCD's.
  Madeira's pull request #567 (by nekodesusan-prog), which brought the Japanese
  locale, bundles the same file.
